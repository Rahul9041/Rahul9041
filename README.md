## Why this profile looks different

Most DevOps profiles list every tool. This one shows **one delivery story**, proven in public repos:

| I care about | What you can actually open |
| --- | --- |
| Pipelines that build and ship | Jenkinsfiles for Maven, Ansible, Docker, and Kubernetes stages |
| Images you can pull | Docker Hub namespace [`rahul9041`](https://hub.docker.com/u/rahul9041) |
| Workloads that run | Kubernetes Deployments, Services, NodePort, readiness probes |
| Hosts that stay consistent | Ansible playbooks for Apache and Docker |
| Simple cloud hosting | S3 + CloudFront + ACM + Route 53 |

No invented production scale. No certification wall. The work is the proof.
